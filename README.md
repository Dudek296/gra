# Gra w rozspójnianie grafu losowego

Statyczna strona z grą o zrównoważonym rozspójnianiu grafów losowych.

Docelowy adres GitHub Pages:

`https://Dudek296.github.io/gra/`

## Tryby gry

- Graf dwumianowy `G(n,p)` z usuwaniem wierzchołków.
- Graf przecięć z oddzielnymi wierzchołkami i cechami, gdzie usuwa się cechy.

## Poziomy trudności

- Łatwy.
- Normalny.
- Własny z ręcznym doborem parametrów.

Strona działa jako pojedynczy plik `index.html` bez procesu budowania.
